# 制作简报：Chrono Divide / vera20k 授权与署名争议

本技能的视频讲同一件事：网页红警一方运营 Chrono Divide 镜像站、注册相关域名和商标、向 vera20k 提交改名 PR，两个项目的作者先后发表声明。视频的任务是把双方说法和公开记录摆清楚，由观众自己判断，不替观众下结论。

写任何分镜之前，先读完本文件和 [`facts.md`](../facts.md)。事实、时间线和每个争议点双方的说法都在 `facts.md`；本文件管怎么讲、用哪张图、哪些话不能说。

## 3. 口径（必须遵守）

- **只陈述，不定性。** 不用“侵占”“盗用”“偷”“抢注”“投毒”“洗白”“皮包公司”这类定性词。说“原作者声明未授权”“PR 把应用名改为王二火大”“记录显示注册者是瑞得哈希”。对方自己用过的词（如“投毒”）可以在引号里原话引用，并说明是谁说的。
- **不用比喻和类比。** 不做历史类比，不把任何人比作历史人物或群体，不用梗图和嘲讽性的配乐、音效、花字。
- **称呼。** 称“网页红警方”或证据里出现的账号名（网页红警、dogemoon）。不提任何个人的真实姓名，不汇总罗列一个人的各平台账号；某个账号只在用到它的那张证据时出现。公司名可以说，它是公开登记信息。
- **事实挂信源。** 说到哪条事实，画面就出示对应的图，旁白按 `facts.md` 的标签说清来源。【未证实】的内容（`facts.md` 第 4 节）不能说成事实。
- **双方说法都要出现。** 每个争议点都要给出网页红警方的说法（如图36、图47、图49、图29、图31），完整、准确，不截取片段，不配反讽的字幕或音效。
- **私信。** 图14、图43、图44、图49 只用来呈现网页红警方本人的说法；图43、图44 必须和图45 成对出现。
- **不用的素材。** 图33、图38。
- **结尾。** 不号召观众做任何针对个人的事；可以提醒观众使用官方渠道、查看项目许可证。
- **打码。** 直接用 `assets/` 下的图片即可，个人信息已模糊；渲染器会自动处理其余打码区域。用其他软件剪辑时，按上表“渲染时”一栏手动打码。

## 5. 各风格改编建议

| 目标 | 做法 | 首选素材 |
| --- | --- | --- |
| 1–3 分钟事件速览 | 按 `facts.md` 的时间线讲，挑 3–4 个争议点，每个都给双方说法 | 图1、图2、图11、图32、图37、图48，配图36、图47 |
| 纪录片 | 放慢节奏，语速 3.5–4 字/秒；截图减少、每张停留更长；环境音和静默多一些 | 每个争议点只用最关键的 2–3 张证据 |
| 出镜讲解 | 主持人按争议点讲，截图做 3–5 秒的画面插入；第二人称、口语化 | 每个争议点挑 2 张，其中一张是对方说法 |
| 新闻资讯 | 导语讲清“两个项目的作者先后发表声明”，客观中性 | 图1、图2、图48 为主，配时间线和图36、图47 |
| 面向海外 / 英文版 | 原作者和 vera20k 作者的声明本身是英文，可直接引用；中文截图配英文说明 | 图1、图2、图5、图7、图22、图23、图32、图45、图48 |
| 单个争议点专题 | 围绕一个争议点讲透，双方说法都给足 | 商标：图1、图30–图32；PR：图36、图37、图47–图49；名称说法：图9、图13、图14、图16 |
