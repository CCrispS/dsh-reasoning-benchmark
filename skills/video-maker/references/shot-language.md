# 镜头语言与时长速查

## 画面类型词表

分镜表"画面类型"列只用下面的词。前一组渲染器可以直接生成；后一组需要另外拍摄或制作，渲染器会先放一张写着"待补素材"的占位卡。

**渲染器能直接生成的**

| 词 | 含义 | 画面内容怎么写 | 字幕/花字怎么写 |
| --- | --- | --- | --- |
| 截图 / 照片 / 档案 | 一张或几张素材图 | `图12`，可加重点"红框圈出注册日期"；多张图写 `图12 图13`，按时长平均轮播 | 有内容时作为下三分之一花字 |
| 字卡 | 纯文字卡 | 背景说明（可省） | `主标题／副标题` |
| 章节卡 | 章节开头 | 章节序号与名称 | `第二章／镜像授权` |
| 引文卡 | 原话或文献引文 | 出处 | 引文正文，出处放在 `／` 后 |
| 数据卡 | 一个大数字或少数几个数字 | 数字含义 | `1.25 万元／瑞得哈希注册资本` |
| 分屏 | 左右对照 | `图5 图7`（左右两张）；不放图时留空 | 无图时写 `左侧文字｜右侧文字` |
| 时间线 | 按日期排列的事件 | 时间范围 | `2023-10 镜像上线；2025-10 注册域名；2026-05 申请商标` |
| 标题卡 / 片头 | 视频标题 | 风格说明 | `主标题／副标题` |
| 片尾 | 结束卡 | 关注引导、信源、致谢 | `片尾主句／补充信息` |

**需要另外拍或做的**：实拍、录屏、动画、出镜、历史影像、空镜、地图。画面内容写清楚要什么；有现成文件时写 `素材: 文件路径`，渲染器会直接使用。

## 运镜与动效

| 词 | 效果 | 什么时候用 |
| --- | --- | --- |
| 固定 | 不动 | 卡片、需要读完的文字 |
| 缓推 | 慢慢放大 | 素材图默认；把注意力引向重点 |
| 缓拉 | 慢慢缩小 | 从局部回到全貌，段落收尾 |
| 左移 / 右移 | 水平平移 | 宽图、并列信息 |
| 下移 | 从上往下滚动 | 长截图、长网页、聊天记录 |
| 上移 | 从下往上 | 由细节回到标题 |

实拍镜头还可以用：推、拉、摇、移、跟、升降、手持、航拍、延时、慢动作。

## 景别（实拍和动画）

| 景别 | 范围 | 作用 |
| --- | --- | --- |
| 远景 | 大环境，人很小 | 交代环境和氛围 |
| 全景 | 人物全身和周围环境 | 交代人物与空间关系 |
| 中景 | 膝盖或腰部以上 | 动作和对话 |
| 近景 | 胸部以上 | 表情和情绪 |
| 特写 | 脸或局部物体 | 强调细节 |

角度：平视（客观）、仰拍（强大）、俯拍（渺小或全局）、主观视角（代入）。

## 转场

| 转场 | 用法 |
| --- | --- |
| 硬切 | 默认，节奏最快 |
| 叠化 | 时间流逝、情绪延续 |
| 黑场 / 白场 | 章节分隔；白场适合闪回或冲击 |
| 匹配剪辑 | 动作、形状或颜色相似的两个镜头相接 |
| 声音先行 | 下一镜的声音提前进入，过渡更自然 |

转场写在"声音/备注"列，例如 `转场：黑场 0.5 秒`。

## 时长换算

| 语速 | 字/秒 | 适用 |
| --- | --- | --- |
| 慢 | 3.5 | 纪录片、抒情、宣传片 |
| 中 | 4.5 | 解说、科普、教程 |
| 快 | 5.5–6 | 短视频、带货、游戏 |

- 镜头时长 ≥ 旁白字数 ÷ 语速 + 0.5 秒呼吸。字数只算汉字和英文单词，标点不算。
- 无旁白的镜头：截图至少 4 秒（观众要读）；字卡按每秒 6–8 字的阅读速度算，最少 2 秒；纯画面 2–5 秒。
- 旁白总量参考：12–14 分钟的完整版、中速，旁白约 2,800–3,200 字；扣掉字卡和纯画面时间后再分到各章。
- 例：一章 120 秒、中速，旁白预算约 120 × 4.5 ≈ 540 字；留出字卡和纯画面时间后，实际写 450 字左右。
