# 风格预设库

选风格时先看速查表，再读对应小节，把参数抄进风格卡后按需调整。本案各风格该讲什么、用哪些证据图，见 `case-brief.md` 第 7 节。两种风格可以组合，例如主体用"解说评论"、历史段落用"纪录片"手法；组合时以主风格的节奏为准。

## 目录

1. 解说评论（事件梳理、证据向）
2. 纪录片（人文、历史）
3. 知识科普（图解、动画）
4. 出镜口播 / 讲课
5. 竖屏短视频（抖音、快手、视频号、小红书）
6. 品牌宣传片 / 情绪片
7. 产品演示 / 软件教程（录屏）
8. 剧情短片 / 情景短剧
9. 新闻资讯 / 播报
10. 游戏视频（实况集锦、攻略、开发日志）
11. Vlog / 纪实跟拍
12. 混剪 / 踩点 MV
13. 访谈 / 对谈

## 1. 解说评论（事件梳理、证据向）

- **适合**：社区事件、争议复盘、商业分析、观点评论、案件梳理。
- **旁白**：单人，沉稳，第三人称陈述。判断之前先给证据；指控类内容用"据……显示""……声明称"。
- **结构**：钩子 → 背景速览（谁、什么、何时）→ 按论点或时间线分段（每段：主张 → 证据 → 小结）→ 总结回扣开头 → 观众能做什么。
- **画面**：截图为主，配红框高亮、日期角标、引文卡。章节卡分段；"说法 vs 事实"之类的对照用分屏。
- **字幕花字**：章节标题；关键日期和数字做角标；当事人原话做引文卡并注明出处。
- **配乐**：低频悬疑或电子氛围；证据揭示处加重音；结论段落渐强，最后一句前骤停。
- **常见错误**：形容词堆砌代替证据；截图一闪而过看不清（每张证据至少停 4 秒，长截图用下移滚动）；没有出处。

## 2. 纪录片（人文、历史）

- **适合**：历史事件、人物传记、地域文化、社会议题。
- **旁白**：慢，留白多，句子短，少用判断词，让画面说话。
- **结构**：意象开场 → 时代背景 → 人物或事件推进（时间线）→ 转折 → 余韵式结尾。
- **画面**：档案照片缓推缓拉（肯·伯恩斯效果）、旧地图、实景空镜、文献特写、采访同期声。
- **字幕花字**：地名和年份角标，档案来源标注；字体偏衬线、克制。
- **配乐**：弦乐、钢琴、环境声；大量使用环境音和静默。
- **常见错误**：旁白塞满不留呼吸；历史画面用错年代；煽情配乐。

## 3. 知识科普（图解、动画）

- **适合**：科学原理、冷知识、经济概念、技术解释。
- **旁白**：亲切、清晰，多用类比，一个概念讲透再讲下一个。
- **结构**：反常识问题 → 直觉答案（通常是错的）→ 逐步拆解 → 核心原理一句话 → 应用或延伸。
- **画面**：示意动画、图解、数据卡、对比分屏、关键词字卡；真实画面用于"锚定"抽象概念。
- **字幕花字**：每个新术语第一次出现时上屏；公式和数字做成数据卡。
- **配乐**：轻快电子或钢琴，讲到关键原理时音乐收一收。
- **常见错误**：一镜塞多个概念；动画说明文字过多；没有回到开头的问题。

## 4. 出镜口播 / 讲课

- **适合**：个人观点、经验分享、课程讲解、知识博主。
- **旁白**：就是出镜人的口播，第二人称"你"，口语化。
- **结构**：观点开场 → 三个左右的要点（每点：观点 → 例子 → 小结）→ 总结 → 互动引导。
- **画面**：A 机中景 + B 机近景交替；讲到具体事物时插 B-roll（截图、实拍、动画）3–5 秒；重点句跳切近景。
- **字幕花字**：要点编号标题、关键词弹出、全程口播字幕。
- **专属写法**：画面类型写"出镜"，在画面内容里注明机位（A 机中景 / B 机近景）。
- **常见错误**：整段固定机位无变化；B-roll 和口播内容不对应。

## 5. 竖屏短视频（抖音、快手、视频号、小红书）

- **适合**：观点切片、知识点、产品种草、事件速览、系列预告。
- **旁白**：快、有力，短句，口语化，直接对观众说话。
- **结构**：0–3 秒钩子（反问、冲突结论、视觉冲击）→ 3–10 秒交代价值 → 主体 2–3 个信息点 → 结尾反转、金句或互动引导（关注看下集、评论区回答）。
- **画面**：画面主体居中，上下留出平台 UI 区域（顶部 15%、底部 20% 不放关键信息）；1.5–3 秒一切；大字花字。
- **字幕花字**：大字号关键词、重点词变色、表情符号适量。
- **配乐**：平台热门节奏型音乐，踩点切换。
- **常见错误**：前 3 秒在铺垫；横屏素材直接缩小放中间（应裁切或模糊铺底）；信息点超过 3 个。

## 6. 品牌宣传片 / 情绪片

- **适合**：品牌形象、活动宣传、城市或机构宣传、产品发布。
- **旁白**：稀疏、有诗意，或完全不用旁白，只靠字幕金句。
- **结构**：情绪起（问题或向往）→ 展开（人、场景、细节）→ 高潮（产品或理念亮相）→ 品牌落版。
- **画面**：高质感实拍、慢动作、航拍、细节特写；镜头之间强调动势连贯。
- **字幕花字**：少而大，金句居中，品牌落版。
- **配乐**：情绪型配乐决定剪辑节奏，高潮处鼓点和画面同步。
- **常见错误**：信息太多；没有核心情绪；落版时间太短（至少 3 秒）。

## 7. 产品演示 / 软件教程（录屏）

- **适合**：软件操作、产品功能介绍、上手指南、问题排查。
- **旁白**：平稳、准确，先说做什么再做；用户界面上的名称原样念出。
- **结构**：最终效果展示 → 准备条件 → 分步骤操作（每步一个小标题）→ 常见问题 → 总结。
- **画面**：录屏为主，鼠标点击处放大或高亮；等待加载的部分加速或剪掉；步骤编号角标。
- **专属写法**：画面类型写"录屏"，画面内容写清操作路径（菜单 › 设置 › 导出）。
- **常见错误**：录屏分辨率太低看不清；操作太快观众跟不上；没有展示最终效果。

## 8. 剧情短片 / 情景短剧

- **适合**：广告短剧、情景演绎、微电影、反转短剧。
- **台词**：角色对白，符合人物身份；旁白很少用。
- **结构**：开场冲突 → 升级 → 反转或高潮 → 结局（短剧在每集末留钩子）。
- **画面**：标准景别语言（远、全、中、近、特写）；正反打对话；动作衔接剪辑。
- **专属写法**：画面内容里写"场景 / 角色 / 动作 / 道具"；台词前标角色名（`甲：……`）。需要时可在表后附场景表和角色表。
- **常见错误**：台词书面化；镜头没有景别变化；反转缺少铺垫。

## 9. 新闻资讯 / 播报

- **适合**：行业新闻、版本更新、活动公告、周报。
- **旁白**：客观、中性，导语讲清"何时何地何人何事"，不评论或明确标出评论部分。
- **结构**：导语 → 详情（按重要性递减）→ 背景 → 后续影响或下一步。
- **画面**：新闻素材、截图、数据卡、地图、字卡；主播出镜可选。
- **字幕花字**：新闻标题条、时间地点角标、信源标注。
- **常见错误**：标题党；把推测当事实；没有信源。

## 10. 游戏视频（实况集锦、攻略、开发日志）

- **适合**：精彩集锦、玩法攻略、版本介绍、开发记录。
- **旁白**：玩家口吻，懂行、带情绪；攻略类准确清晰。
- **结构**：高光开场 → 主题交代 → 主体（集锦按情绪递进，攻略按步骤，开发日志按问题 → 方案 → 效果）→ 结尾高光或下期预告。
- **画面**：游戏实录为主，关键操作慢放或暂停加标注，地图俯视全景，界面元素放大。
- **字幕花字**：击杀数、资源数等数字角标，技能或单位名称标注。
- **配乐**：激昂电子或游戏原声风格，交战处踩点。
- **常见错误**：长时间无事发生的实录；界面文字太小；只有画面没有讲解重点。

## 11. Vlog / 纪实跟拍

- **适合**：日常记录、旅行、活动现场、幕后花絮。
- **旁白**：第一人称，随意自然，可以加后期补录的内心独白。
- **结构**：今天要做什么 → 过程（按时间）→ 意外或亮点 → 感想收尾。
- **画面**：手持跟拍、第一视角、环境空镜、延时摄影；跳切压缩时间。
- **常见错误**：素材冗长不剪；没有主线；收音嘈杂。

## 12. 混剪 / 踩点 MV

- **适合**：角色混剪、年度回顾、预告片、氛围短片。
- **旁白**：通常没有；可以用影片原声台词做点缀。
- **结构**：跟随音乐结构（前奏 → 主歌 → 副歌 → 尾奏），副歌放最强画面。
- **画面**：每镜对准节拍点切换；动作方向在相邻镜头间延续；转场用闪白、遮罩、动作匹配。
- **专属写法**：时长列写到 0.1 秒，备注里标节拍点或歌词位置。
- **常见错误**：不踩点；画面情绪和音乐段落不匹配；素材版权未处理。

## 13. 访谈 / 对谈

- **适合**：人物专访、圆桌对谈、播客视频版。
- **声音**：采访同期声为主，主持人提问可以字卡代替。
- **结构**：最有力的一句话开场 → 人物介绍 → 按话题分段（问题字卡 → 回答 → B-roll）→ 收尾金句。
- **画面**：受访者中近景双机位；讲到具体事物时插 B-roll；问题用字卡。
- **专属写法**：旁白列写同期声原话或时间码（`[12:30–13:05] 受访者：……`）。
- **常见错误**：同期声段落太长不插画面；问题和回答对不上。

## 把模糊描述翻译成参数

| 用户说 | 风格卡里写 |
| --- | --- |
| 高级感 | 镜长拉长到 4–6 秒，画面留白，低饱和色调，字幕少而小，配乐钢琴或氛围音，减少花字 |
| 节奏快一点 | 平均镜长减半，语速提到 5–5.5 字/秒，每 15 秒一次视觉重置，配乐换成节奏型 |
| 严肃 / 正式 | 去掉表情和花哨花字，色调偏冷，旁白第三人称，信源标注齐全 |
| 有梗 / 轻松 | 允许夸张花字和音效，镜头可以跳切，旁白加口语和反问，但事实部分保持准确 |
| 像纪录片 | 采用第 2 节参数，旁白放慢，多用档案画面缓推和环境音 |
| 适合发抖音 | 采用第 5 节参数，9:16，总长控制在 60 秒内，前 3 秒放结论 |
