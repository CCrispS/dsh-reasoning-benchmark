# 《两份声明之后：Chrono Divide 与 vera20k 授权争议》分镜稿

## 项目概要与风格卡

一条中立的说明视频：Chrono Divide 和 vera20k 两个项目的作者，在 2026 年 10–11 月先后就网页红警一方发表声明。视频按争议点，把原作者或公开记录的说法、网页红警方的说法、目前能确认的事实依次摆出来，由观众自己判断，不替观众下结论。受众是关注网页版红警和开源社区的 B 站观众；交付这份完整版分镜和对应的渲染规格 `render/full.json`。

| 项目 | 设定 |
| --- | --- |
| 平台与画幅 | B 站横屏 16:9，1920×1080 |
| 时长 | 13 分 33 秒（813 秒），10 章，92 镜 |
| 平均镜长 | 约 8.8 秒 |
| 旁白 | 单人、沉稳、第三人称陈述，中速 4.5 字/秒；每句按 `facts.md` 的来源标签交代是谁说的，原话加引号 |
| 开场方式 | 两个项目作者的声明，加上网页红警方的公开回应；不设悬念，不预设结论 |
| 画面基调 | 深色证据风：证据截图为主，红框只标出被引用的原文；字卡深色底白字 |
| 字幕与花字 | 截图左下角只写来源和日期（谁、在哪、何时）；每个争议点结尾一张“能确认的”字卡；不用评价性花字 |
| 配乐与音效 | 低音量、平稳的氛围铺底，章节处转段；不用强调或嘲讽性的音效 |
| 转场 | 硬切为主，章节之间黑场 0.5 秒 |

**假设**：

- 依据只有 `facts.md` 和 `references/case-brief.md`；旁白里的每条事实都能在 `facts.md` 找到对应条目和证据图。引用网页红警方的原话时，按证据截图原文完整引用。
- 结构按制作简报第 1 节：开场 → 当事方 → 争议点 A–F → 其他说法（G/H/I）→ 结尾。每个争议点按“原作者或记录 → 网页红警方的说法 → 能确认什么”讲。
- 称呼统一用“原作者”“vera20k 作者”“网页红警方”，以及证据里出现的账号名“网页红警”“dogemoon”；不提任何人的真实姓名。
- 全部画面用 `assets/` 里的证据截图和渲染器生成的字卡，不需要另找素材。
